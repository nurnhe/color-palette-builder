# Shade Studio

A personal makeup palette generator that installs on your phone as a web app.

- **New palette**: bold color-wheel combos (or classic makeup tones with the Wearable style in Settings).
- **Start from colors**: type hex codes or words like `warm brown, gold` or `smoky plum`.
- **Lock and reroll**: tap a shade to keep it, reroll the rest. Tap a hex code to copy it.
- **Settings**: default number of colors (1 to 12), style, and Eyes / Full face.
- **Saved palettes** stay on your device.

Live: https://nurnhe.github.io/color-palette-builder/

## Editing

Edit `src/app.html`, then run `python3 build.py` to regenerate `index.html`.
